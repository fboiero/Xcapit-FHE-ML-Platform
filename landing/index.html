Tecnologia

Cifrado Homomorfico Completo (FHE)

El FHE permite realizar operaciones matematicas sobre datos cifrados sin necesidad de descifrarlos. Utilizamos el esquema CKKS optimizado para operaciones de punto flotante, ideal para Machine Learning.

1

Encriptacion Local

Los datos se cifran en tu servidor con tu clave privada antes de transmitirse.

2

Procesamiento Seguro

Nuestros modelos ML operan sobre los datos cifrados. Sin acceso a informacion en claro.

3

Resultados Encriptados

Las predicciones vuelven cifradas. Solo tu puedes descifrarlas con tu clave.

example.py 
from xcapit_fhe import FHEContext, LinearRegression

# Inicializar contexto FHE
ctx = FHEContext()
ctx.create_keys()

# Encriptar datos localmente
X_enc = ctx.encrypt(X_train)
y_enc = ctx.encrypt(y_train)

# Entrenar sobre datos cifrados
model = LinearRegression()
model.fit(X_enc, y_enc)  # Sin descifrar!

# Predicciones cifradas
predictions_enc = model.predict(X_test_enc)

# Solo tu puedes descifrar
results = ctx.decrypt(predictions_enc)
