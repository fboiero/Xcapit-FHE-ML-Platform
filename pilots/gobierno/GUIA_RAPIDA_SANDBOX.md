## Acceso al Sandbox

**URL**: https://xcapit-privacy.vercel.app

## Recorrido Recomendado (15 minutos)

### PASO 1: Registro (2 min)

1. Click en **"Empezar Gratis"** o **"Start Free"**
2. Completar registro:
   - Nombre: `Demo - [Su Agencia]`
   - Email: su email corporativo
3. Acceder al Dashboard

---

### PASO 2: Dashboard Principal (2 min)

Al ingresar vera:
- **Metricas generales** del sistema
- **Consorcios activos** (demos pre-cargados)
- **Actividad reciente**

> **Tip**: El dashboard simula datos de un consorcio inter-bancario.
> Para Provincia de Córdoba, imagine que "Banco Alpha" = DGR, "Banco Beta" = Min. Desarrollo Social, "Banco Gamma" = CIDI.

---

### PASO 3: Gobernanza Blockchain (5 min)

**Navegacion**: Menu lateral → **Governance**

#### 3.1 Contributions (Contribuciones)
- Vea que aporto cada participante
- **Registros**: Cantidad de datos contribuidos
- **Features**: Variables del dataset
- **Peso**: Porcentaje de participacion
- **Verificado**: Prueba criptografica en blockchain

#### 3.2 Proposals (Propuestas)
- Sistema de votacion descentralizado
- Tipos de propuestas:
  - Agregar/Remover miembros
  - Iniciar entrenamiento
  - Distribuir recompensas
- Barra de progreso de votacion
- **Pruebe votar** en una propuesta activa

#### 3.3 Audit Trail (Auditoria)
- Historial inmutable de todas las operaciones
- Cada evento tiene timestamp y actor
- Auditable por cualquier participante

---

### PASO 4: Demo de Consorcio (4 min)

**Navegacion**: Menu lateral → **Demos**

1. Seleccione **"Multi-Party Consortium"**
2. Elija el escenario **"Banks"** (simula agencias gubernamentales)
3. Click **"Start Demo"**
4. Observe paso a paso:
   - Como cada participante cifra sus datos
   - Como el modelo entrena sin ver datos
   - Como se generan resultados

> **Importante**: En ningun momento los datos se descifran.
> Las operaciones matematicas se realizan directamente sobre datos cifrados.

---

### PASO 5: Compliance (2 min)

**Navegacion**: Menu lateral → **Compliance**

- Verificacion automatica de regulaciones:
  - GDPR
  - HIPAA
  - SOC2
  - PCI-DSS
- Genere un **reporte de auditoria**
- Vea el estado de compliance en tiempo real

## Funcionalidades Clave para Provincia de Córdoba

### 1. Privacidad por Diseno
- Los datos de ciudadanos cordobeses **nunca** se descifran
- Cumplimiento automatico de Ley 9.380 (Protección de Datos Personales de Córdoba)
- Cada organismo provincial mantiene soberania de sus datos

### 2. Transparencia Total
- Todas las operaciones quedan en blockchain
- Auditable por organismos de control
- Trazabilidad de decisiones

### 3. Colaboracion Segura
- ML colaborativo entre organismos provinciales
- Sin necesidad de transferir datos entre DGR, Min. Desarrollo Social, CIDI y municipios
- Mejor deteccion de fraude y elegibilidad cruzando informacion

### 4. Gobernanza Democratica
- Decisiones por votacion entre organismos
- Cada organismo provincial tiene voz y voto
- Quorum configurable segun normativa provincial

## Preguntas Frecuentes

**P: Los datos salen de mi infraestructura provincial?**
R: No. Solo se comparten datos cifrados. Las claves privadas nunca salen de cada organismo (DGR, Min. Desarrollo Social, CIDI, etc.).

**P: Que pasa si un organismo es comprometido?**
R: Solo verian datos cifrados. Sin la clave privada, son inutiles.

**P: Como se garantiza el compliance?**
R: El sistema verifica automaticamente y genera reportes auditables.

**P: Puedo integrar con mis sistemas actuales?**
R: Si. Tenemos SDK en Python y TypeScript, mas API REST.
