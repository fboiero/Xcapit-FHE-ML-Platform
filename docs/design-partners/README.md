# Design Partners Program — Xcapit FHE-ML Platform

> **Objetivo**: cerrar 3-5 organizaciones piloto antes del GA (1.0.0) para validar product-market fit y construir casos de uso reales documentables.

## Por qué un programa de Design Partners

Una conversación con un CTO/CISO de un banco real que necesita compartir datos con sus pares vale más que 10 features técnicas. El programa de design partners nos permite:

1. **Validar el problema real** (no el que asumimos)
2. **Co-diseñar el roadmap** con quienes pagan
3. **Construir casos de éxito documentables** para la siguiente ronda
4. **Generar ingresos tempranos** vía contratos de pilot
5. **Construir referencias verticales** (banking, health, insurance, retail)

## Timeline sugerido

| Semana | Hito |
|--------|------|
| 1 | Definir lista de 30 cuentas target (TARGET_LIST.md priorizada) |
| 2 | Primer batch outreach (10 cuentas warm intro + 20 cold) |
| 3-4 | Discovery calls (objetivo: 5-8 reuniones) |
| 5-6 | Demo + propuesta de pilot (objetivo: 3-4 propuestas formales) |
| 7-8 | Cierre de 3-5 contratos de pilot |
| 9-20 | Ejecución de pilots en paralelo (90 días cada uno) |
| 21+ | Conversión a clientes pagos + casos de éxito publicados |

## Reglas no negociables del programa

1. **Honestidad sobre el estado del producto**: somos RC1, no GA. Lo decimos siempre.
2. **No firmamos NDAs antes del primer call**: friction killer. Si insisten, walking away cuesta menos que un mal NDA.
3. **No piloteamos gratis sin métricas**: incluso pilots gratuitos deben tener success metrics firmadas.
4. **Máximo 5 pilots simultáneos**: más es muerte por dilución de atención.
5. **Cada pilot tiene un ejecutivo sponsor de Xcapit**: founder o C-level, no se delega.
