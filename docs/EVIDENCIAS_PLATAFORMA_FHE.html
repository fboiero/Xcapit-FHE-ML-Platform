2. Proceso de Encriptación FHE (CKKS)

El esquema CKKS permite realizar operaciones aritméticas aproximadas sobre números reales encriptados, ideal para machine learning.

2.1 Flujo de Encriptación

1
Generación de Contexto
Se crean los parámetros criptográficos y las claves pública/privada
from sdk.encryption import CKKSEncryptor, SecurityLevel # Crear encriptador con seguridad de 128 bits encryptor = CKKSEncryptor( security_level=SecurityLevel.BITS_128, poly_modulus_degree=8192, scale=2**40 ) # Output: """ Contexto CKKS creado: - Seguridad: 128 bits - Grado polinomial: 8192 - Escala: 1099511627776 - Claves generadas: pública, privada, galois """
2
Codificación de Datos
Los números reales se codifican como polinomios
# Datos originales (transacción financiera) transaction = [1732.03, 4, 10.4, 0.85] # monto, hora, distancia, score # Codificar como polinomio encoded = encryptor.encode(transaction) # Output: Polynomial de grado 8191 con coeficientes complejos
3
Encriptación con Clave Pública
El polinomio se encripta usando la clave pública
# Encriptar datos ciphertext = encryptor.encrypt(transaction) # Output: """ Ciphertext generado: - Tamaño: 131,072 bytes (128 KB) - Componentes: (c0, c1) - par de polinomios - Nivel de ruido: 40 bits disponibles """ print(f"Expansión de datos: {len(ciphertext) / len(transaction) / 8:.0f}x") # Output: Expansión de datos: ~4000x

3.2 Operaciones Homomórficas Básicas

Demostración de operaciones sobre datos cifrados:

# Datos originales a = [1.5, 2.5, 3.5] b = [0.5, 1.0, 1.5] # Encriptar a_enc = encryptor.encrypt(a) b_enc = encryptor.encrypt(b) # SUMA sobre datos cifrados sum_enc = a_enc + b_enc sum_dec = encryptor.decrypt(sum_enc) # Resultado: [2.0, 3.5, 5.0] ✅ # MULTIPLICACIÓN sobre datos cifrados mul_enc = a_enc * b_enc mul_dec = encryptor.decrypt(mul_enc) # Resultado: [0.75, 2.5, 5.25] ✅ # PRODUCTO PUNTO (dot product) - crucial para ML weights = [0.3, 0.5, 0.2] dot_enc = a_enc.dot(weights) dot_dec = encryptor.decrypt(dot_enc) # Resultado: 2.4 ✅ (= 1.5*0.3 + 2.5*0.5 + 3.5*0.2)

✅ Las operaciones sobre datos cifrados producen resultados matemáticamente correctos.

3.3 Inferencia de Modelo sobre Ciphertext

# Cargar modelo entrenado model = FHELogisticRegression.load("fraud_detector_v1.model") # Nueva transacción (encriptada por el cliente) new_transaction = encryptor.encrypt([5200.00, 2, 800.0, 0.98]) # Predicción sobre datos CIFRADOS (en el servidor) prediction_enc = model.predict(new_transaction) # El servidor NUNCA ve los datos originales # Solo el cliente puede descifrar el resultado prediction = encryptor.decrypt(prediction_enc) # Output: {"is_fraud": true, "probability": 0.943}

4.2 Protocolo Commit-Reveal

🔒 FASE 1: COMMIT (Votos Ocultos)

Cada banco envía un hash de su voto + salt aleatorio:

🇦🇷 Alpha: 0x8a39e49f485334a6...

🇨🇱 Beta: 0xf840aa26640768c4...

🇲🇽 Gamma: 0x543c89b96fded6d2...

Voto: ??? (oculto)
Nadie puede ver cómo votaron los demás.

🔓 FASE 2: REVEAL (Votos Verificados)

Cada banco revela su voto + salt original:

🇦🇷 Alpha: ✅ SÍ - VERIFICADO

🇨🇱 Beta: ✅ SÍ - VERIFICADO

🇲🇽 Gamma: ✅ SÍ - VERIFICADO

Resultado: 3/3 (100%)
Quórum: 51% requerido → APROBADO
